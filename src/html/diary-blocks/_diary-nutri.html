Метод расчёта нутрицевтики

Значение на 100 г × вес порции ÷ 100, затем сумма по продуктам выбранного приёма или дня. Продукты без точных данных по нутриенту не учитываются.

Как читать рекомендации

Расчёт по 5 из 7 продуктов (71% съеденного по весу). Реальное потребление может быть выше.

Откуда данные по нутрицевтике

Данные о витаминах, минералах и других веществах доступны только для части продуктов. Они взяты из открытых справочных баз и данных производителей.

  • Полные данные: заполнено большинство нутриентов.
  • Частично: известны отдельные показатели.
  • Только КБЖУ: нет точных данных о нутриентах, например у домашних блюд с переменным составом.

Сумма учитывает только известные количества. Отсутствие данных не означает отсутствие вещества.
